 \hypertarget{md_doc_2NETWORK_autotoc_md26}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{md_doc_2NETWORK_autotoc_md26}
This documentation provides a detailed explanation of the {\bfseries{Network Module}} used in the game engine. The network module facilitates communication between the server and client using the {\bfseries{UDP protocol}}. It integrates with the {\bfseries{\doxylink{classECS}{ECS} (Entity-\/\+Component-\/\+System)}} architecture and leverages events to manage network requests and responses.

The module is composed of the following components\+:
\begin{DoxyEnumerate}
\item {\bfseries{\doxylink{classUDPServer}{UDPServer}}}\+: Handles server-\/side communication.
\item {\bfseries{\doxylink{classUDPClient}{UDPClient}}}\+: Handles client-\/side communication.
\item {\bfseries{\doxylink{classServerHandlerSystem}{Server\+Handler\+System}}}\+: Processes incoming requests on the server.
\item {\bfseries{\doxylink{classClientHandlerSystem}{Client\+Handler\+System}}}\+: Processes incoming responses on the client.
\item {\bfseries{Events}}\+: {\ttfamily \doxylink{structRequestEvent}{Request\+Event}} and {\ttfamily \doxylink{structReceiveEvent}{Receive\+Event}} are used to manage communication.
\end{DoxyEnumerate}

\hypertarget{md_doc_2NETWORK_autotoc_md47}{}\doxysubsection{\texorpdfstring{Server Workflow\+:}{Server Workflow:}}\label{md_doc_2NETWORK_autotoc_md47}

\begin{DoxyEnumerate}
\item The server starts and listens for requests on a specific port using {\ttfamily \doxylink{classUDPServer}{UDPServer}}.
\item A client sends a request, triggering a {\ttfamily \doxylink{structRequestEvent}{Request\+Event}}.
\item The server processes the event and generates a {\ttfamily \doxylink{structReceiveEvent}{Receive\+Event}}.
\item The {\ttfamily \doxylink{classServerHandlerSystem}{Server\+Handler\+System}} processes the received data and sends a response back if necessary.
\end{DoxyEnumerate}\hypertarget{md_doc_2NETWORK_autotoc_md48}{}\doxysubsection{\texorpdfstring{Client Workflow\+:}{Client Workflow:}}\label{md_doc_2NETWORK_autotoc_md48}

\begin{DoxyEnumerate}
\item The client initializes and connects to the server using {\ttfamily \doxylink{classUDPClient}{UDPClient}}.
\item A {\ttfamily \doxylink{structRequestEvent}{Request\+Event}} is posted to send data to the server.
\item The server processes the request and sends a response.
\item The client processes the response using {\ttfamily \doxylink{classClientHandlerSystem}{Client\+Handler\+System}} when a {\ttfamily \doxylink{structReceiveEvent}{Receive\+Event}} is triggered.
\end{DoxyEnumerate}

\hypertarget{md_doc_2NETWORK_autotoc_md50}{}\doxysection{\texorpdfstring{Conclusion}{Conclusion}}\label{md_doc_2NETWORK_autotoc_md50}
The network module provides a robust and event-\/driven framework for communication between the client and server. By leveraging the \doxylink{classECS}{ECS} architecture, the network logic remains modular and easy to maintain. This design ensures scalability and flexibility for game development or other applications requiring real-\/time communication.
