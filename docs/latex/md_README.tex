{\bfseries{R-\/\+Type}} is an iconic arcade game developed by Irem in 1987. This {\bfseries{horizontal scrolling shoot \textquotesingle{}em up}} places the player in the cockpit of a spacecraft, the {\bfseries{R-\/9 Arrowhead}}, to combat the extraterrestrial threat known as the {\bfseries{Bydo Empire}}.\hypertarget{md_README_autotoc_md75}{}\doxysection{\texorpdfstring{Technologies Used}{Technologies Used}}\label{md_README_autotoc_md75}

\begin{DoxyItemize}
\item {\bfseries{Programming Languages\+:}} Python and C++
\item {\bfseries{Graphics Library\+:}} \href{https://www.sfml-dev.org/}{\texttt{ SFML}}
\item {\bfseries{Audio Management\+:}} Integrated via SFML
\end{DoxyItemize}
